# Rankked desktop releases

Official distribution repository for Rankked. Release assets include Windows/macOS installers, checksums, a reviewed application source snapshot, and dependency source/license materials. No private development history is included.

Application source is distributed under AGPL-3.0 as stated in LICENSE.md. Dependency licenses and corresponding-source materials accompany each release; consult the notices inside the source archive.

Current desktop builds are unsigned; macOS builds are not notarized. Review the release notes before installing.

Website: https://rankked.com

Stable download page: https://rankked.com/descargar
